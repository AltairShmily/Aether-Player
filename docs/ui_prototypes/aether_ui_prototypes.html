01 服务器选择页 server_selection_screen.dart

入口页。星空粒子 + 顶部青色光晕；居中 440px 列：Logo → AETHER → 服务器列表 →「添加新服务器」。卡片可点自动登录，也可删除。

桌面 / 平板 440 × 约 720
02 登录页 login_screen.dart

两阶段表单：先「连接」服务器地址，成功后展开用户名/密码与「登录」。左对齐 420px 卡片，顶部径向光晕。

阶段 A · 未连接 输入地址 → 连接
阶段 B · 已连接 展开账号密码
03 主壳 Shell · 宽屏侧边栏 shell_screen.dart

断点 ≥720px：72px 侧边栏（Logo / 首页 / 媒体库着色钮 / 搜索 / TV模式 / 服务器切换 / 设置）+ 右侧内容 Navigator。<720px 切换为底部四栏导航。

宽屏 Shell 骨架 侧栏 72 + 内容
紧凑布局 <720px 底部导航
04 首页 HomeTab home_tab.dart

双层径向光晕背景 + CustomScrollView。自上而下：App Bar（Logo/搜索/刷新）→ 欢迎语 → Hero 轮播（继续观看）→ 继续观看横滑 → 媒体库快捷 → 分类 Chip → 各库横滑 → 账户卡片。

桌面首页 内容区示意
05 媒体库 phone_library_screen.dart

两层结构：库网格（16:10 卡，自适应列，最大块宽 300）→ 点击进入库内容页（2:3 海报网格，最大块宽 150，带返回栏）。

库网格视图
库内容页 · 海报网格
06 剧集总览 SeriesDetail series_detail_screen.dart

Aether 风格：300px Backdrop Hero + 170×255 海报上移 70 压住 Hero → 菱形徽章/标题/状态 → Meta/类型 → 播放 Pill → 简介 → 季 Tab → 横向集预览 + 纵向集列表 → 演员横滑。

桌面剧集详情
07 单集详情 EpisodeDetail episode_detail_screen.dart

≥1200px 双栏：左侧 16:9 封面 + 面包屑/标题/简介/演职/进度；右侧 360px 固定控制面板（媒体源 / 音频 / 字幕 / 全宽播放按钮）。<1200 单栏堆叠。

桌面双栏布局
08 视频播放器 PlayerPage player_page.dart

横屏全屏。单击显隐 OSD；双击左右 1/3 快退/进 10s，中间播放/暂停。顶栏高 100（返回/标题/设置）；底栏：进度条 + 快退10/播放52/快进30/下一集 | 音量/倍速/调参。暂停时中央 72px 大播放钮。右上 Direct Play / Transcode 角标。

播放中 · OSD 显示
设置底部弹窗
09 音频播放器 AudioPlayer audio_player_page.dart

竖屏全屏。紫色径向光晕背景；顶部收起/「正在播放」/收藏；中央 280×280 旋转专辑封面；曲名/歌手；AetherProgress；控制行 shuffle / 上一首 / 64 渐变播放钮 / 下一首 / 循环。

音频全屏页
10 搜索 search_overlay.dart · tv_search_overlay.dart

桌面/手机 Ctrl+K：毛玻璃遮罩 + 居中 560px 搜索面板（仅输入提交，无结果列表）。TV：全屏 87% 黑遮罩 + 560 搜索框 + 6 列 2:3 结果网格，遥控器聚焦放大。

全局搜索 Ctrl+K

11 设置 settings_modal.dart · settings_tab.dart · tv_home_screen.dart

Shell 实际使用精简弹窗 SettingsModal（520 宽）：播放 / 外观 / 网络。另有完整 SettingsTab（账户卡 + 播放/外观/语言/网络/服务器管理/关于/登出）。TV 设置为大屏分组页。

12 TV 模式主页 tv_home_screen.dart

D-Pad 焦点导航，左右边距 56。顶栏 80 高（渐变 Logo + 主页/电影/剧集/动漫/设置 + 搜索 + 时钟）。推荐横幅 21:9 聚焦 scale 1.01 + 青 3px 边；媒体卡 190 宽聚焦 scale 1.08；库卡 260×146。
