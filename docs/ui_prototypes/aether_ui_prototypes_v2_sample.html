✦ UI 原型优化方案 · 示例 v2

对 docs/ui_prototypes/aether_ui_prototypes.html 的结构批评与可落地改进 · 仍对齐 Celestial Glow 令牌

P0 · 可用性

只有 happy path

现有 12 页几乎全是「有内容」态。空态 / 加载骨架 / 错误重试才是实现时最先分叉的路径，原型必须成组出现。

P0 · 保真

灰块占位信息量不足

海报是纯 #1A2332 矩形，看不出 2:3 比例、底部渐变、评分角标、进度条——这些恰是 MediaCard 的识别特征。

P1 · 标注

无尺寸 / Token / 热区

实现同学无法从原型直接读到「侧栏 72 / 卡宽 152 / 圆角 12 / 点击进详情」。缺少标注层等于只有一张画。

P1 · 对照

三端未并排

Desktop / Phone / TV 分散在不同 section，难以对比同一信息架构在不同断点下的折叠策略（720 断点、56 TV 边距）。

P1 · 交互

静止，无状态演示

Hover 播放钮、聚焦 TV 焦点环、Toggle 开关是 Celestial Glow 的招牌交互，静帧无法传达。

P2 · 维护

手绘 SVG 易漂移

每页独立手绘，源码改间距后原型不同步。应抽成 组件图例 + 模板复用，并写明「与源码对齐的锚点文件」。

OPT-06错误/空态文案规范（写进原型，不写在代码注释里）

原型应固定「界面自己的声音」：说明出了什么、下一步做什么。避免「加载失败」「出了点问题」。

场景不推荐推荐（写入原型）动作
本地代理未起 加载失败 无法连接本地代理服务。请确认 aether-server 与程序同目录。
Emby 401 登录失败 用户名或密码不正确，或该账号无权访问此服务器。 焦点回到密码框
空媒体库 暂无内容（单独一行） 这个媒体库里还没有可播放的项目。 Ghost「刷新」
播放轨道为空 （隐藏菜单） 没有可选字幕轨道。 禁用行，保留标题
搜索无结果 未找到相关结果 没有找到「{keyword}」。试试更短的关键词。 保持输入框焦点

OPT-07建议落地节奏

阶段交付物验收
第 1 步 · 词典 组件图例页（Card / Pill / Toggle / Progress / Badge / 错误条） 与 widgets/ 源码一一对应，有尺寸注释
第 2 步 · 主路径精修 Shell + 首页 + 剧集详情 + 集详情 + 播放器（5 页）高保真 + 热区 每页含 2+ 状态；桌面/手机成对
第 3 步 · 补全 登录两阶段、设置弹窗、TV 焦点流、搜索双实现 三端对照表无空行
第 4 步 · 维护机制 原型页脚标注「对齐 commit / 源文件」；改 UI 先改图例再改页面 与 docs/ui_gap_analysis.md 联动更新
