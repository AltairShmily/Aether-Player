01

媒体库页

phone_library_screen.dart

现状是「库网格 + 库内容网格」两层，但库卡信息弱（只写「点击查看」）、无数量、无筛选/排序，内容页只有海报墙。 目标：把媒体库做成可浏览、可筛选、可感知规模的主入口，而不是图标墙。

现状问题

  • 库卡副文案写死 「点击查看」，不传达任何信息 phone_library_screen.dart:200
  • 无条目数量 / 未看数，用户无法判断库里有什么
  • 库卡无右侧光晕、无 Hover 阴影复合（gap_analysis #7.2–7.3）
  • 内容页只有返回 + 海报网格，无类型筛选、排序、视图切换
  • 海报卡无评分角标（网格视图）
  • 空库 / 加载 / 错误未单独设计（直接空列表）
  • 点击库卡用 MaterialPageRoute，未用统一 AetherPageRoute 右滑 :139

目标改法

  • 库卡副文案 → 「128 部 · 12 未看」（DM Mono，来自 ItemsCount / UserData）
  • 库卡补右侧 radial 光晕 + Hover：Y-4 scale 1.02 + 复合阴影
  • 库卡圆角统一 radiusLg 16（现部分用 Md）
  • 内容页顶栏加：类型 Chip（全部/电影/剧集）+ 排序（最近添加 / 名称 / 年份）
  • 海报网格卡：右上评分角标（有 Rating 时）+ 底部标题渐变
  • 网格 hover：Y-4 scale 1.03 + 播放钮（同 MediaCard）
  • 导航改 AetherPageRoute.fadeSlide，与首页一致
  • 四态：骨架 / 空库文案 / 代理错误 / 正常

02

剧集页 SeriesDetail

series_detail_screen.dart

已是 Celestial Glow 实现最好的详情页，但仍有信息重复（横向预览 + 纵向列表双份）、首播入口弱、 空季/加载态简陋、版本切换埋得深等问题。目标：把「选哪一集、接着看」压缩到首屏一屏内完成。

现状问题

  • 集列表横向 10 张预览 + 纵向全量重复展示，首屏被吃掉 :683–722
  • 「播放」Pill 点第一集，不考虑未看完的进度，无法「接着看」 :499
  • 加载中只有一个转圈（:631），无骨架行
  • 空季直接 SizedBox.shrink()，用户不知道是没数据还是没请求到
  • 多版本集（merged.versions）在 Tile 里展开，但横向卡片看不出多版本
  • 演员区空则隐藏，无占位说明
  • 季 Tab 指示器与 gap_analysis 有偏差（间距、padding）
  • 海报与 Hero 重叠区在超宽屏下比例略飘（gap #4.1–4.2）

目标改法

  • 砍掉横向预览行，改为「继续观看条」：有进度的 1–3 集横向小卡 + 进度，其余进纵向列表
  • 主按钮逻辑：有未看完 →「继续播放 SxxExx」；否则 →「播放 S01E01」
  • 纵向列表加已看勾 / 当前集高亮左边线（青 2px）
  • 加载：3 行骨架 Tile（缩略图 130×73 + 两行灰条）
  • 空季：「本季还没有剧集」+「刷新」
  • 多版本：Tile 尾部徽章「N 版本」可点，弹底部选择（勿嵌套展开挤压布局）
  • 演员区空 → 显示「暂无演职人员信息」灰字，不整段消失
  • Hero 遮罩改双层（gap 规范：to-top + to-right）
  • 海报 170×255 / 圆角 16 / 青描边 12%（对齐 HTML 规范）

03

播放 UI PlayerPage

player_page.dart · video_osd.dart · quality_selector.dart

手势与进度已可用，但 OSD 信息层级乱、设置路径深（倍速只能点循环 / 弹窗）、字幕/音轨不可视、 缓冲与错误态弱。目标：达到「单手可盲操、字幕一秒切换、出错能自救」。

现状问题

  • 底栏控件挤在一行：快退 / 播放 / 快进 / 下一集 + 音量滑条 + 倍速芯片 + 调参 :980–1110
  • 倍速是点击循环，无法直接选 1.5x；要打开底部弹窗 :1106–1109
  • 音量滑条固定 宽 70，平板/电视难拖
  • 无字幕语言角标（看不到「当前中字」）
  • 缓冲只有居中 spinner，无进度百分比/缓冲条
  • 错误提示位置在底部 120，和 OSD 抢层 错误覆盖层
  • 自动下一集卡片有，但取消/立即按钮热区偏小
  • 桌面 VideoOsd 与手机自绘 OSD 是两套逻辑，行为不一致 widgets/video_osd.dart
  • 无「章节 / 跳过片头」入口（Emby 有 IntroMarkers 时）

目标改法

  • 底栏两行： ① 进度条（左已播 / 中条 / 右总长，拖动显示目标时间）
    ② 左：退10 · 播放52 · 进30 · 下一集　右：字幕 · 音量 · 倍速 · 画质 · 更多
  • 倍速改为长按/点开 Chip 菜单（0.5–2.0 直选），当前值常显
  • 字幕按钮旁加当前语言短标签（中/英/关）
  • 音量：图标可静音；滑条宽度随容器 min(120, 20%)
  • 缓冲：进度条上亮色缓冲段 + 中央细环，不挡画面中心字幕区
  • 错误：居中卡片（非底部条）：原因一句 +「重试」/「返回」/「切换画质」
  • 片头/片尾：有 Marker 时进度条上方出现「跳过片头」胶囊，自动 8s 消失
  • 统一：把 PlayerPage 的 OSD 抽到 VideoOsd，桌面/手机共用，只换布局密度
  • 下一集倒计时按钮 ≥44×44，文案「立即播放 / 取消」

04

建议改造顺序

优先级改动页理由预估
P0 主按钮「接着看」+ 改名带集号 剧集 最高频路径，一行逻辑 0.5d
P0 播放器字幕一级入口 + 语言角标 播放 看外挂字幕刚需 1d
P0 库卡数量/未看 + 去掉「点击查看」 媒体库 信息密度，文案硬伤 1d
P1 剧集列表去重：继续观看条 + 纵向列表 剧集 首屏效率 1.5d
P1 播放 OSD 两行化 + 倍速直选 播放 盲操体验 2d
P1 库内容筛选 Chip + 排序 媒体库 片库变大后的刚需 1.5d
P1 三页骨架/空/错误态补齐 全部 与 gap_analysis 同步 2d
P2 跳过片头 / 缓冲段 / 错误卡片 播放 体验加分 1.5d
P2 OSD 组件统一到 video_osd 播放 防双实现漂移 2d
P2 Hero/海报像素对齐 HTML 规范 剧集 对照 ui_gap_analysis 0.5d
